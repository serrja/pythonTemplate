# Producer feature and update matrix

This source-only index is owned by pythonTemplate. It records reviewed implementation snapshots, not GitHub release status or package publication. Follow the pinned configuration and test links when refreshing it; do not copy this page into generated applications.

## Features and defaults

The maintained commands for all four producers pin Copier 9.17.2 and preserve a lowercase Python import package derived from the project name. `withTesting` and `withCi` default to true. The CLI and FastAPI producers reject CI without testing; serviceTemplate defaults its hidden `withTesting` answer to true. Licenses remain an explicit generated-project choice.

The parent receipts record `dirtyTracked=false` for these snapshots: [CLI receipt](https://github.com/serrja/typerTemplate/blob/d67e097f85d8304c9e28d21db1c20ce30808e8c5/_sources/pythonTemplate/sourceIdentity.json), [API receipt](https://github.com/serrja/fastapiTemplate/blob/f75a79cdb8bc28caf2a91a398aa8c11a51d13713/_sources/pythonTemplate/sourceIdentity.json), [service receipt](https://github.com/pokerlost/serviceTemplate/blob/72cf17d2d90576050bdd12badd2ebc12070d5b1b/_sources/fastApiTemplate/sourceIdentity.json). `composition.lock.json` records the generated bytes and ownership. A parent HEAD and a content digest have different meanings; never replace a reviewed source with mutable `main` or infer release readiness from a native version field.

Persistence-enabled HTTP renders require an explicitly supplied PostgreSQL DSN. Database-free defaults require no DSN. Database acceptance uses a disposable PostgreSQL instance; a mocked readiness failure is not database acceptance. Kubernetes remains opt-in; an explicit existing answer survives a later default change. Foundation tests measure infrastructure behavior, not application-domain correctness. The service [archive regressions](https://github.com/pokerlost/serviceTemplate/blob/72cf17d2d90576050bdd12badd2ebc12070d5b1b/tests/test_sdk_acceptance.py) cover nested distributions and missing acceptance markers with synthetic files and a Docker stub; they do not establish application-image acceptance.

The reviewed [FastAPI configuration contract](https://github.com/serrja/fastapiTemplate/blob/f75a79cdb8bc28caf2a91a398aa8c11a51d13713/docs/development.md) separates deployment identity (`main`, `dev`, `test`, `local`) through `*_RUNTIME_ENVIRONMENT` from the existing telemetry execution contour (`local`, `dev`, `ci`, `remote`) through `*_ENVIRONMENT`. Explicit constructor values retain priority. Owners configure endpoints, credentials, databases and namespaces separately; neither setting derives from Git. Existing applications own their settings, so carry the documented field/source contract into those files explicitly and run the managed settings regressions while preserving log/DSN aliases. Copier preserves project ownership rather than replacing those settings.

## Render and verify

Run the maintained render command from the chosen clean producer checkout. Set `TEMPLATE_SHA` to the full reviewed source above and `DESTINATION` to a new disposable directory; substitute the row's render answers:

```bash
uvx --from 'copier==9.17.2' copier copy --defaults --vcs-ref="$TEMPLATE_SHA" . "$DESTINATION"   -d projectName=sampleLibrary -d profile=library
```

The CLI/API rows use their own project answers; the service row uses `service_name`. Add explicit `withPersistence=true` or `withKubernetes=true` only to the applicable HTTP producer. Verify a fresh render with its generated instructions (`uv lock`, `make install`, `make check`, `make build`). Native needs its compiler/CMake toolchain. Existing applications retain their committed dependency lock; do not silently re-resolve it during an update. SDK-bearing service builds retain their existing narrow admission and credential policies.

```bash
uvx --from 'copier==9.17.2' copier update --defaults --vcs-ref="$NEW_TEMPLATE_SHA"
```

Copier owns `.copier-answers.yml`; do not edit its source/ref to simulate an update or replace update with forced copy. Inspect the Git index as well as command exit status: overlapping edits can leave conflict markers even when Copier exits zero. Preserve applied historical revisions. The shared composition suite also checks snapshot drift, failed smoke propagation and deterministic provenance.

Producer maintenance uses its own locked toolchain and `make check`; refresh commands differ by parent boundary and are documented in [CLI maintenance](https://github.com/serrja/typerTemplate/blob/d67e097f85d8304c9e28d21db1c20ce30808e8c5/README.md#-maintenance), [API maintenance](https://github.com/serrja/fastapiTemplate/blob/f75a79cdb8bc28caf2a91a398aa8c11a51d13713/README.md) and [service maintenance](https://github.com/pokerlost/serviceTemplate/blob/72cf17d2d90576050bdd12badd2ebc12070d5b1b/README.md#-maintenance). This index links those commands instead of introducing another updater or copying generated files manually.
