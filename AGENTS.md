# pythonTemplate

This repository owns the common Python Copier foundation and engineering policy. Owned Python follows PEP 8: snake_case modules, functions, variables, and internal fields; CapWords classes; UPPER_SNAKE_CASE constants. Preserve established repository names, Copier answers, CLI and wire contracts. CLI scaffolding belongs to typerTemplate; HTTP scaffolding belongs to fastApiTemplate. Historical service/native profiles remain for compatibility. Do not introduce product contracts, credentials, post-generation hooks, or business behavior. Add focused technical and regression tests for composition, packaging, and generated mechanisms. Run a disposable render for each retained profile and verify generated metadata, links, and available build commands. Keep user-owned files intact during updates.
